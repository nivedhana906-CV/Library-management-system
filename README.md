# LIBRARY MANAGEMENT SYSTEM

## 1. Introduction

The Library Management System is a web-based application developed to manage library book records easily and efficiently. It helps users add, view, update, search, and delete book information.

The system reduces manual work and makes book management simple and organized.

## 2. Objective

The main objective of the Library Management System is to provide an easy way to manage books in a library.

The objectives are:

* To add new book details.
* To view available books.
* To search for books.
* To update book information.
* To delete book records.
* To manage issued and available books.
* To reduce manual record maintenance.

## 3. Features

## 5. System Modules

### 5.1 Book Management

This module is used to add and manage book details such as book name, author, book ID, category, and status.

### 5.2 Search Module

The search module helps users find a particular book quickly using the book name, author name, or book ID.

### 5.3 Update Module

This module allows users to modify existing book information.

### 5.4 Delete Module

This module allows users to remove unwanted book records from the database.

### 5.5 Status Management

The book status can be maintained as either Available or Issued.

## 6. CRUD Operations

The system performs four basic CRUD operations.

**Create:** Add a new book.

**Read:** Display book records.

**Update:** Modify existing book details.

**Delete:** Remove book records.

## 7. Database Design

The system uses an SQLite database to store book information.

### Books Table

| Field     | Description                  |
| --------- | ---------------------------- |
| ID        | Unique book record number    |
| Book Name | Name of the book             |
| Author    | Author of the book           |
| Book ID   | Unique book identification   |
| Category  | Type or category of the book |
| Status    | Available or Issued          |
